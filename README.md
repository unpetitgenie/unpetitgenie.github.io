- **STS2 Mod Playlist**: v0.2 Steam Workshop 공개
- **STS2 Skin Select Tool**: 개발 중단
- **슝더슝지니**: Slay the Spire 2 플레이 판단과 실패 원인을 기록하는 내부 연구 프로젝트

사이트는 현재 공개 상태와 지난 작업을 함께 소개합니다. 페이지니 테스터 신청 링크는 모집 중단에 맞춰 제거했습니다.
